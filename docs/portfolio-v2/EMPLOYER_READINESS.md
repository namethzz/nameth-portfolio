# Internship-ready portfolio QA

## Goal
Present clear evidence of work for Front-end and Full-stack internships, without generic overclaiming or employer-specific branding.

## Implemented on the v2 feature branch
- First-screen internship role and **availability Jan 4 – Apr 23, 2027** (university dates, not a guarantee that a different company start date is approved).
- Concise first-person About Me in Thai/English.
- Source-backed engineering sections in all three case studies.
- Screenshots from THAI TAY's published `preview/` directory.
- A guarded CI workflow to capture OTW's **real public storefront**, with validations so an error page cannot masquerade as project work.
- Live links and honest labels separating completed work and project work in progress.

## Open items before submitting applications
- Verify the OTW screenshot capture workflow succeeded and only then use its image in the portfolio.
- Add genuine Economic Crops Chat frontend screenshots, captured from the real project with an accurate note on whether the backend was connected.
- Verify OTW and THAI TAY live demos on desktop and mobile, especially after any new deploy.
- Review the downloaded resume and dates for consistency with the university.
- Publish reviewed v2 to a public preview URL; localhost is not a shareable portfolio.
- Run manual keyboard/visual review, not just CI.
- Ask HOD whether a Jan 6 start is compatible with Jan 4 university dates or use its flexible option.

## Principles
Don't invent traffic, performance numbers, commercial results, completed ML forecasts, or ownership of a teammate's RAG code. Keep source code links and screenshots verifiable.
